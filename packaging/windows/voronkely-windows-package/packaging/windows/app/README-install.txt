Voronkely - installation Windows
================================

1. Copiez le dossier complet sur le poste client.
2. Exécutez start-voronkely.bat.
3. L'application démarre sur http://localhost:8080.

Notes importantes :
- La base SQLite sera créée dans : %APPDATA%\Voronkely\data\voronkely.db
- Les images importées seront stockées dans le dossier data du profil utilisateur.
- Si Java 17 n'est pas installé, installez-le avant de lancer l'application.
